# 私募资管权限到期自动提醒——具体操作步骤与效果说明

## 1. 具体操作步骤/方案

1. **整理客户权限台账**：从业务系统导出《客户私募资管权限有效期》Excel 表（示例路径：
   `D:\数据\客户资管权限有效期台账.xlsx`），要求第 2 行为列头，
   包含"客户号、客户姓名、专业投资者到期日期、私募基金到期日期、资管权限到期日期"等列；
   日期列兼容 `20261021` 数字、文本、日期等多种格式，无需统一转换。

2. **获取并运行工具**：将"权限到期提醒.exe"放入独立文件夹双击运行（便携式，首次启动需
   解压、稍慢属正常；程序在 exe 同目录生成 `config.json`、`data\`、`logs\`）。
   如无 exe，可源码运行：进入 `permission_reminder` 目录 → `python -m venv .venv` →
   `.venv\Scripts\pip install -r requirements.txt` → `.venv\Scripts\python app.py`。

3. **配置发件邮箱**：在界面"邮箱配置"区先选预设（腾讯企业邮箱 / 163 / 自建邮局等），
   填写发件邮箱、SMTP 服务器与端口、加密方式、授权码、目标邮箱，点"保存邮箱配置"。
   关键参数：自建邮局的发信服务器填**发件域 MX 记录指向的主机**（如 `mailex1.单位域名`），
   端口 **25 + STARTTLS**（465/587 多数未开放），不要填 `mail.域名`（只是网页门户前端）；
   授权码不是网页登录密码——登录网页版邮箱 → 设置 → 安全设置/客户端设置 →
   生成"客户端专用密码/授权码"后填入。填好先点"**发送测试邮件**"验证；
   连不上或认证失败点"**连接诊断**"，按报告给出的推荐配置"一键套用"。
   注意：认证被拒（如 `535 reject by CACTER gateway`）时**不要反复重试**，避免单位出口 IP
   被网关封禁；若一时拿不到授权码，把"发送方式"切到"**本机邮件客户端**"兜底模式——
   只需填目标邮箱，程序把提醒导出为 `.eml` 并自动唤起 Foxmail 发送，完全不碰 SMTP。

4. **做一次 Foxmail 集成（推荐）**：先在本机安装 Foxmail 并配好单位邮箱账号；
   回到工具在"Foxmail"一栏点"**自动检测**"（自动扫描注册表/卸载信息/常见目录定位
   `Foxmail.exe`），再点"**测试唤起**"验证。集成后兜底通道直接用 Foxmail 投递，
   避免误用个人版 Outlook 发送客户信息。

5. **加载数据并启动定时**：点"**选择 Excel 文件**"加载台账，勾选检查范围
   （专业投资者 / 私募基金 / 资管权限三项，默认全选），保持"**检查前自动同步**"勾选
   （自动获取最新法定节假日，保证"前推 5 个工作日"计算准确），设置每天检查时间
   （如 09:00）后点"**启动定时任务**"，程序保持运行即可；当天漏检，3 天内启动会自动补发。

6. **收到提醒后的跟进动作与话术要点**：提醒邮件主题为"【权限到期提醒】"，正文逐户列出
   客户号、客户姓名、权限类型与到期日。经办人按名单在到期前电话联系客户，话术要点：
   "您好，您名下的 XX 权限将于 X 月 X 日到期，为避免影响您后续参与私募基金/资管产品交易，
   请在到期前完成重新认证/资料更新手续，我行（司）可协助办理，稍后把办理指引发到您的邮箱"；
   跟进结果在台账中登记销号，已办理的无需再关注，未联系上的次日继续跟进。

## 2. 效果与作用

将过去"人工逐户翻台账、凭记忆盯日期"的被动管理，升级为"系统自动筛查、邮件自动提醒、
人员按单跟进"的主动管理：程序在每项权限**到期日前推 5 个工作日**当天自动发送汇总提醒
（自动排除周末与法定节假日），漏检自动补发、同户同权限只提醒一次，从机制上杜绝漏提醒；
授权码/发送方式一次性配置后长期自动值守，大幅减少人工核对工作量；权限到期处置提前量
稳定在 5 个工作日以上，有效降低因权限失效导致的客户交易中断、投诉与合规风险。
其他机构只需按上述步骤配置 Excel 台账与邮箱，即可直接复制使用。
