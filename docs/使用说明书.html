一、软件简介与主要功能

本工具面向客户私募资管权限的到期管理：选定 Excel 台账后，程序按「到期日前推 5 个工作日」 判定触发日（自动排除周末与法定节假日），当天把所有命中项汇成一封邮件发出； 当天没开机也不怕，3 天窗口内启动会自动补发（邮件主题标注【补发】）。

主要功能一览

功能说明
邮箱配置发件邮箱、SMTP 服务器/端口、加密方式（SSL / STARTTLS / 不加密）、授权码、多个目标邮箱，一键保存；内置 QQ / 163 / 腾讯企业邮箱 / 自建邮局预设；可发送测试邮件验证；「清除邮箱配置」只清邮箱相关，不影响其他设置

二、快速上手（六步完成配置）

1
配置邮箱：填写 SMTP 信息（可先选预设）、发件邮箱、授权码（QQ 邮箱请用「设置 → 账户」里生成的授权码而非登录密码）、目标邮箱（多个用英文逗号分隔），点击 保存邮箱配置；建议先点 发送测试邮件 确认能收到。若超时或认证失败，点 连接诊断，报告会指出断在哪一环。
企业邮箱（腾讯企业邮 / 网易企业邮等）通常必须使用服务商生成的客户端专用密码 / 授权码，不能填网页登录密码。
2
选择数据文件：点击 选择 Excel 文件，选中客户权限有效期表。格式要求：第 2 行为列头，含客户号、客户姓名、三个权限的开通/到期日期列；日期列兼容多种格式（如 20261021）。
3
勾选检查范围：默认三项全查（专业投资者 / 私募基金 / 资管权限），可按需取消。
4
节假日：保持 检查前自动同步 勾选（默认开启）即可。也可手动点 同步最新节假日 立即拉取并弹出「休假计划」窗口；无网络时点 查看休假计划 只看本地缓存。
5
设置定时：调整时/分，点击 启动定时任务。程序需保持运行；关闭后定时停止，重新打开会自动恢复调度并补检漏掉的提醒。
6
立即检查：随时点击 立即检查并发送提醒 手动跑一次（与定时共享去重记录）。

三、发送方式二选一（邮箱配置区第四行）

方式何时用需要填什么
SMTP 直发（默认）正常情况服务器 + 端口 + 加密方式 + 发件人 + 授权码 + 目标邮箱
本机邮件客户端单位邮件网关拒绝第三方客户端认证（如 535 reject by CACTER gateway），一时拿不到客户端专用密码只需目标邮箱（不需要服务器/授权码/密码）

「本机邮件客户端」模式的工作流程

  1. 把汇总邮件导出到 data\outbox\ 目录，生成一对同名文件（权限到期提醒_日期-时间.eml + .html，同秒多次导出自动加序号，不覆盖）；
  2. 唤起邮件客户端投递 —— 优先 Foxmail（已集成时），否则用系统默认邮件客户端；
  3. 弹窗确认是否已成功发送——选「是」才标记已发；选「否」不标记，下次检查会再次提醒。

投递目标的选择顺序

优先级情况工具行为
①已集成 Foxmail唤起 Foxmail 打开导出的 .eml（或弹写信窗口），由它用自己配好的单位账号投递
②未集成 Foxmail，但有系统默认邮件客户端唤起系统默认客户端的新建邮件窗口（收件人/主题/正文摘要已预填），并提示去做 Foxmail 集成
③两者都没有不唤起任何窗口，直接打开导出目录，请手动双击 .eml 发送
其他按钮： 「导出邮件到本地」只导出 .eml + .html 并核对排版，不发送、不标记已发； 「打开导出目录」用资源管理器打开 data\outbox\，可把 .eml 拖进 Foxmail 或双击后发送。
为什么这样能绕开网关：投递由 Foxmail/Outlook 用它自己已配置好、能正常发信的凭据完成，本工具完全不碰 SMTP，因此不涉及第三方客户端的认证策略。

三种唤起方式的取舍

方式特点
打开导出邮件(.eml)
（默认，最可靠）		命令形如 Foxmail.exe "……\权限到期提醒_xxx.eml"。只是"用某个程序打开某个文件"，不依赖任何私有命令行参数，兼容性最好；在 Foxmail 里点「转发 / 再次编辑 → 发送」即完成投递
新建写信窗口(mailto)命令形如 Foxmail.exe "mailto:…?subject=…&body=…"，直接弹出新建邮件窗口并预填内容，少一步点击，但依赖 Foxmail 对 mailto 启动参数的支持
自动有 .eml 时用前者，没有时退回后者
若某种方式在你这台机器上没反应，把「唤起方式」换成另一种再点 测试唤起 试一次即可。 集成只负责唤起，最后一步的「发送」始终由你在 Foxmail 里点 —— 所以工具不会替你把邮件当成"已发送"。

关于"系统默认邮件客户端"

工具会先用 Windows 的关联查询接口探测默认客户端到底是 Foxmail、Outlook 还是 Windows 自带邮件应用，并在提示里写清楚，避免"以为在发 Foxmail、实际弹了别的东西"。两种特殊情况：

  • 没有设置默认邮件客户端：点 mailto: 只会弹出 Windows 的「选取应用」框，毫无帮助，所以工具不会去打开它，改为自动打开导出目录，请手动双击 .eml（用 Foxmail 等已配好单位账号的客户端）发送；
  • 默认客户端不是单位邮箱（例如个人 Microsoft 账号的「新版 Outlook」）：请改用 Foxmail 打开导出的 .eml 发送，或做 Foxmail 集成让工具直接走 Foxmail。
⚠ 合规提醒：提醒邮件含客户号与客户姓名，请务必用单位邮箱发送，不要使用个人邮箱。

五、单位自建邮局特别注意事项（Coremail / Exchange 等）

  • 发信服务器不是 mail.你的域名，而是发件域 MX 记录指向的那台主机（例如 mailex1.你的域名）。"mail.域名"往往只是负载均衡/Web 门户前端，连得上但根本不说 SMTP —— 点一次 连接诊断，它会查 MX 并逐一实测，把可用端点填进「推荐配置」，一键套用即可。
  • 加密方式：自建邮局常用 25 端口 + STARTTLS（本工具已支持）；若服务器不支持 STARTTLS，则选不加密。
  • 密码：若用网页登录密码认证被拒（535），请登录网页版邮箱 → 设置 → 安全设置/客户端设置，生成客户端专用密码 / 授权码填入。
  • 别连点发送/测试：网关会按出口 IP 统计认证失败次数并临时封禁（报 554 ... Smtp auth error limit exceeded）。工具已内置 10 分钟冷静期与"失败不重试"兜底，但请先确认密码再试。
  • 拿不到正确凭据时的应急通道：把「发送方式」切到本机邮件客户端 —— 不需要授权码/密码，只填目标邮箱，工具把提醒导出成 .eml 由你手动投递。这条通道不碰 SMTP，完全绕过网关的客户端认证策略。
  • 建议顺手做一次 Foxmail 集成：在「Foxmail」一栏点 自动检测，检测到后点 测试唤起 验证。集成后本工具会直接用 Foxmail 投递，不再依赖系统默认邮件程序（避免默认的是个人版 Outlook）。若尚未安装 Foxmail，请先安装并在其中配好单位邮箱账号，再回来点 自动检测。

六、提醒规则

  • 触发时点：到期日前推 5 个工作日（排除周末和法定节假日）当天触发；
  • 邮件形式：一封汇总邮件列出所有命中项，主题固定为【权限到期提醒】；
  • 漏检补发：错过触发时点（程序未开机等），在 3 天窗口内启动会自动补发，主题标注【补发】；
  • 去重：同一客户、同一权限、同一触发日只发一次；手动检查、定时任务、补检共享发送记录。

七、常见问题（FAQ）

现象处理
发送失败提示 timed out（超时）先点「连接诊断」。最常见两个原因：① 服务器/端口填错（如把 443 当 SMTP 端口，标准应为 465 或 587）；② 该地址根本不是发信服务器（如把 mail.域名 当发信服务器，而它只是负载均衡前端）。诊断会查 MX 并逐一实测，给出可用的推荐配置
服务器"连得上"但发送仍失败典型的假连接：TCP 握手被接受却没有任何 SMTP 服务号。诊断的"服务号探测"环节会明确标出，并在"MX 端点"环节找到真正的发信服务器。注意：TCP 能连不等于这里有邮件服务
发送失败提示 535 authentication failed密码类型不对或客户端策略受限：企业邮箱必须用客户端专用密码 / 授权码，不能填网页登录密码；自建邮局可能要求生成客户端专用密码，或需管理员把你的账号/出口 IP 加入允许范围。点「连接诊断」会按服务商给出具体步骤
提示 535 reject by CACTER gateway, Error: Unknown error这条 535 是安全网关回的策略拒绝，不等于密码写错，不要只反复改密码重试。按成本从低到高自查：① 浏览器登录网页版邮箱，确认当前密码（工具里存的若是很久以前的初始密码，很可能已过期或被强制更换）；② 网页版 → 设置 → 安全/客户端设置 → 生成客户端专用密码（授权码）填入，不要填网页登录密码；③ 确认发件服务器是 MX 记录指向的主机 + 25 端口（STARTTLS），而不是 mail.你的域名（后者常只是前端，"连得上但没有 SMTP 响应"）；④ 若单位启用客户端白名单，用邮件客户端手工配同一账号发一封测试邮件：能发 → 白名单策略，请管理员把本机出口 IP 加入允许范围；同样发不出 → 回到 ①②。这条提示会先探测本机环境再给建议：若本机没有可用的默认邮件客户端，它会明确告诉你这一步在本机走不通，并改指「本机邮件客户端」兜底模式
一时拿不到正确密码，但今天就要发提醒把「发送方式」切到本机邮件客户端：只需目标邮箱，检查时导出到 data\outbox\ 并唤起邮件客户端投递。选「否 / 稍后」不标记已发，下次检查仍会提醒，可放心先跑起来
怎么把 Foxmail 集成进来① 先安装 Foxmail 并配好单位邮箱账号（能正常收发）；② 回本工具点 自动检测（自动扫描注册表、卸载信息、常见安装目录、PATH）；③ 点 测试唤起 验证——能弹出测试邮件/写信窗口即成功。装在非默认位置时用 浏览… 手动指定。完成后每次检查都会直接用 Foxmail 投递
点「自动检测」提示未检测到 Foxmail说明机器上确实没有 Foxmail 的安装痕迹。若确定装了，用 浏览… 手动指定 Foxmail.exe。常见位置：C:\Foxmail 7.2\（安装器默认目录）、C:\Program Files (x86)\Foxmail\、D:\Foxmail\
点「测试唤起」Foxmail 没反应换一种「唤起方式」再试：先试打开导出邮件(.eml)（最可靠），不行再试新建写信窗口(mailto)。测试邮件会导出到 data\outbox\，也可直接双击它手工验证
已集成 Foxmail，但还是弹了别的客户端检查「Foxmail 路径」是否有效（点 自动检测 或 浏览… 重设）。路径无效时工具会回落到系统默认客户端，并在确认弹窗里写明"未使用 Foxmail"。也可点 设为默认邮件程序 把 MAILTO 指定为 Foxmail
不想让工具去动系统设置放心：设为默认邮件程序只负责打开 Windows 的「默认应用」页，真正的修改由 Windows 在用户确认下完成，本工具不写任何注册表，也不会改 Foxmail 的配置或数据文件
切换兜底模式后没弹出写信窗口说明本机既没集成 Foxmail，也没有默认邮件客户端。工具会主动跳过唤起，改为打开导出目录——双击 .eml，用 Foxmail 等已配好单位账号的客户端打开发送即可。建议先做 Foxmail 集成，之后就能自动唤起
兜底模式下弹出的不是 Foxmail工具会在提示里写明实际用的是哪个客户端。若是个人账号的「新版 Outlook」等，不要用它发——提醒含客户号与姓名。推荐直接做 Foxmail 集成
不确定该填哪台服务器、哪个端口实测方法：对发件域做 MX 查询，再逐端口探测，只认真正返回 SMTP 服务号（220）的那台主机。这些都可以由「连接诊断」自动完成
服务器返回 554 ... Smtp auth error limit exceeded本机出口 IP 已被对方邮件安全网关临时封禁（认证失败次数超限）。属 IP 级临时封禁，通常等待一段时间自动解除，也可请管理员解封。封禁期间请勿反复重试；工具已内置"失败不重试 + 10 分钟冷静期"兜底
提示"已暂停发送：…冷静期"上一步认证失败后进入了保护性冷静期。确认已修正密码/服务器地址后，保存邮箱配置（或一键套用推荐配置）即可立即解除
提示"目标邮箱格式不正确"目标邮箱有笔误（如漏了 .com 的点），到"邮箱配置"修正并保存即可。这类错误被提前拦截，不再浪费重试
测试邮件发送失败：SMTP 认证失败检查授权码（不是登录密码）、端口与加密方式（SSL/STARTTLS/不加密）是否匹配
提示 Excel 缺少关键列确认表头在第 2 行且列名完全一致（如"专业投资者到期日期"）
日志显示"无 XXXX 年节假日数据"升级 chinese-calendar，或点"同步最新节假日"拉取在线数据；当年会自动降级为仅排周末，不影响使用
同步节假日失败（网络不通）内网/无网络时为正常降级：仍使用本地缓存 + 内置数据；联网后再点一次"同步最新节假日"即可
内网环境能否关闭"检查前自动同步"可以：取消"节假日"区的 检查前自动同步 复选框，改为手动点"同步最新节假日"
想重新发送今天已发过的邮件删除 data/sent_records.json 中对应条目（或整个文件）后再次检查

data/sent_records.json发送记录（去重依据）
data/holidays.json节假日同步缓存
data/outbox/兜底通道导出的 .eml / .html
logs/app.log日志（2MB 轮转，保留 5 份）

节假日数据源：主源 timor.tech，备用源 holiday-cn；同步失败自动尝试备用源，全部失败时回退本地缓存/内置数据并在日志中记录（内网环境属正常降级，不影响使用）。 配置项 auto_sync_holidays（默认开启）对应「检查前自动同步」复选框；send_mode（smtp / client）对应「发送方式」单选钮；foxmail_path 与 foxmail_mode（auto / eml / mailto）对应「Foxmail」一栏，改完即时保存。

九、附录：源码运行与打包

从源码运行（需 Windows + Python 3.10+，依赖 pandas、openpyxl、chinese-calendar）

cd permission_reminder → python -m venv .venv → .venv\Scripts\pip install -r requirements.txt → 启动：.venv\Scripts\python app.py

打包为单文件 exe

.venv\Scripts\pyinstaller --onefile --noconsole --name 权限到期提醒 --collect-data chinese_calendar app.py， 产物在 dist\权限到期提醒.exe。

  • --noconsole：双击运行不弹黑色控制台窗口；
  • exe 是便携式的：首次运行在 exe 同目录生成 config.json、logs/、data/，建议单独放一个文件夹；
  • 首次启动较慢（单文件 exe 需解压到临时目录），属正常现象；若杀毒软件误报，请加入白名单或改用 --onedir 模式。
